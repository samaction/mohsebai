# 🤖 بوت تلغرام المحاسبي الذكي (AI Accountant Telegram Bot)

هذا هو السكربت الخارجي للوكيل الذكي الذي يستقبل الرسائل من تلغرام ويقوم بتسجيل المعاملات الماليّة ومزامنتها لحظياً مع تطبيق الأندرويد.

## 🚀 طريقة التشغيل خلال دقيقة:

1. افتح تلغرام وابحث عن `@BotFather` واكتب `/newbot` للحصول على **Bot Token**.
2. ضع توكن البوت في ملف `index.js` بدلاً من `YOUR_TELEGRAM_BOT_TOKEN_HERE`.
3. قم بتنزيل ملف `serviceAccountKey.json` من **Firebase Console** وضعه في هذا المجلد.
4. نفذ الأوامر التالية في الـ Terminal:

```bash
cd telegram-bot
npm install
npm start
```

مبروك! أصبح البوت يعمل رسمياً ومربوطاً بذاكرة تطبيق الأندرويد سحابياً!
